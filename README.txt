HOME EXPENSES v2
================
النسخة الثانية أصبحت مجهزة لتعمل كتطبيق PWA مستقل.

الجديد:
- أيقونة للتطبيق.
- Manifest للتثبيت على الشاشة الرئيسية.
- وضع Standalone: بعد التثبيت يفتح كتطبيق مستقل.
- Service Worker للتشغيل بدون إنترنت بعد أول تحميل.
- الاحتفاظ بكل البيانات محلياً على الهاتف.

مهم:
فتح index.html مباشرة من WhatsApp بصيغة file/content لا يسمح عادةً بتثبيت PWA أو تشغيل Service Worker.
لذلك بعد اختبار الوظائف، سنضع هذه الملفات على استضافة HTTPS مجانية (مثل GitHub Pages)،
ثم تفتح الرابط مرة واحدة في Chrome وتختار "إضافة إلى الشاشة الرئيسية / Install app".
بعد التثبيت سيظهر التطبيق بأيقونته ويفتح كبرنامج مستقل، ويمكن أن يعمل Offline.

لا يوجد Login ولا قاعدة بيانات خارجية في هذا التصميم.
